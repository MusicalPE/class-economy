교실 경제 시스템 2.0 — 설치 안내
================================================================

2.0부터 구조가 바뀌었습니다.

   화면          GitHub Pages (한 곳에만 올려 두고 모두가 씁니다)
   자료·계산      선생님의 스프레드시트 (자료는 여기에만 남습니다)

화면을 고치면 모든 학급에 바로 적용되고, 선생님은 스프레드시트에
아주 짧은 껍데기 코드 하나만 두면 됩니다.


----------------------------------------------------------------
1단계. 저장소에 화면 올리기  (제작자만 한 번)
----------------------------------------------------------------

MusicalPE/class-economy 저장소에 이 파일들을 올립니다.

   index.html
   css/style.css
   js/api.js
   js/app.js
   README.md

gas 폴더와 shell 폴더도 함께 올려 두면 나중에 찾기 편합니다.
(화면과 상관없는 파일이라 올리지 않아도 작동에는 지장 없습니다.)

올린 뒤 GitHub Pages를 켭니다.

   저장소 > Settings > Pages
   Source: Deploy from a branch
   Branch: main / (root)  → Save

몇 분 뒤 아래 주소가 열리면 됩니다.

   https://musicalpe.github.io/class-economy/

이때 "학급 연결이 필요합니다" 화면이 나오는 것이 정상입니다.
아직 어느 학급에도 연결되지 않았다는 뜻입니다.


----------------------------------------------------------------
2단계. 라이브러리 만들기  (제작자만 한 번)
----------------------------------------------------------------

(1) script.google.com 에서 "새 프로젝트"를 만듭니다.
    ※ 스프레드시트에서 만들지 말고, 반드시 독립 프로젝트로 만드세요.

(2) 프로젝트 이름을 "교실 경제 시스템 라이브러리" 정도로 바꿉니다.

(3) gas/Code.gs 의 내용을 통째로 붙여 넣고 저장합니다.

(4) 배포 > 새 배포 > 유형 선택(톱니바퀴) > 라이브러리 > 배포

(5) 프로젝트 설정(왼쪽 톱니바퀴)에서 스크립트 ID를 복사해 둡니다.
    3단계에서 씁니다.

앞으로 기능을 고칠 때는 이 프로젝트만 고치고 배포 > 새 배포로
버전을 올리면 됩니다.


----------------------------------------------------------------
3단계. 학급 스프레드시트 연결
----------------------------------------------------------------

[이미 쓰고 있던 학급이라면]
  지금 쓰는 스프레드시트를 그대로 씁니다. 자료가 남아 있습니다.

[새로 시작한다면]
  빈 스프레드시트를 하나 만듭니다. 시트는 저절로 만들어집니다.

(1) 스프레드시트에서 확장 프로그램 > Apps Script 를 엽니다.

(2) 기존에 있던 Code.gs 와 Index.html 의 내용을 모두 지웁니다.
    (Index.html 파일 자체를 지워도 됩니다. 이제 쓰지 않습니다.)

(3) shell/Shell.gs 의 내용을 Code.gs 자리에 붙여 넣습니다.

(4) 왼쪽 "라이브러리 +" 를 누르고
      스크립트 ID  : 2단계에서 복사한 ID
      버전         : 가장 높은 번호
      식별자       : CE          ← 반드시 CE 여야 합니다
    추가합니다.

(5) 배포합니다.

    처음 설치라면  : 배포 > 새 배포 > 웹 앱
    쓰던 학급이라면: 배포 > 배포 관리 > (연필) > 버전: 새 버전 > 배포
                     이렇게 해야 학생들이 쓰던 주소가 그대로 유지됩니다.
                     새 배포를 만들면 주소가 바뀌어 다시 알려 줘야 합니다.

    설정은 두 가지 모두 이렇게 둡니다.
      실행 사용자 : 나
      액세스 권한 : 모든 사용자

(6) 스프레드시트로 돌아와 새로고침하면 위쪽에 "교실 경제" 메뉴가
    생깁니다.


----------------------------------------------------------------
4단계. 마무리
----------------------------------------------------------------

교실 경제 메뉴에서 차례로 눌러 줍니다.

  · 자동 처리 켜기
      매일 0시 10분 물품 자동 리필, 매일 9시 적금 만기 처리를
      예약합니다. 처음 한 번만 누르면 됩니다.

  · 이전 판 설정 가져오기
      2.0 이전부터 쓰던 학급만 누르면 됩니다.
      제목·로고·테마 색·이자율·관리자 비밀번호를 옮겨 옵니다.
      새로 설치했다면 누를 필요 없습니다.

  · 접속 주소 보기
      학생들에게 알려 줄 주소가 나옵니다.
      이 주소로 들어오면 화면이 저절로 열립니다.


----------------------------------------------------------------
달라진 점
----------------------------------------------------------------

[설정이 '설정' 시트로 옮겨졌습니다]

  예전에는 제목·로고·테마·이자율·관리자 비밀번호를 스크립트
  속성에 저장했습니다. 그런데 여러 학교가 같은 라이브러리를
  쓰면 그 값이 학교끼리 섞일 수 있습니다.

  그래서 스프레드시트 안에 '설정' 시트를 새로 만들고 거기에
  저장합니다. 선생님이 직접 열어 볼 수도 있고, 학교끼리 섞일
  걱정도 없습니다.

[화면 파일을 더 이상 붙여 넣지 않습니다]

  예전에는 새 판이 나올 때마다 Index.html 을 통째로 다시
  붙여 넣어야 했습니다. 이제 화면은 GitHub에 있어서, 선생님은
  아무것도 하지 않아도 최신 화면이 열립니다.

[ES5 변환이 필요 없어졌습니다]

  화면이 Apps Script를 거치지 않으므로 템플릿 리터럴(백틱)을
  그대로 써도 됩니다. 1.x 때 화면 전체를 멈추게 했던 그 문제가
  구조적으로 사라졌습니다.


----------------------------------------------------------------
잘 안 될 때
----------------------------------------------------------------

"학급 연결이 필요합니다" 가 계속 나온다
  → 접속 주소 보기에서 나온 주소로 들어갔는지 확인하세요.
    주소는 /exec 로 끝나야 합니다.

"서버 주소가 올바르지 않거나 배포 설정이 잘못되었습니다"
  → 배포할 때 액세스 권한이 '모든 사용자' 인지 확인하세요.
    '나만' 으로 되어 있으면 학생이 들어올 수 없습니다.

"CE is not defined"
  → 라이브러리 식별자가 CE 가 맞는지 확인하세요.

화면이 옛 모습 그대로다
  → 브라우저가 옛 파일을 기억하고 있는 것입니다.
    Ctrl+Shift+R 로 새로고침하세요.
